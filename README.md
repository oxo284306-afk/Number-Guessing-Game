# Number Guessing Game

A simple and interactive number guessing game built with Python.

## Features

- 🎯 Three difficulty levels:
  - Easy: Number from 1 to 10, with 10 attempts.
  - Medium: Number from 1 to 50, with 7 attempts.
  - Hard: Number from 1 to 100, with 5 attempts.
- 🔢 Attempt counter.
- 🚫 Maximum attempts limit.
- 📊 Shows remaining attempts.
- 🛡️ Handles invalid input using try/except.
- 📏 Prevents guesses outside the allowed range.
- 🔄 Play again option.
- 🧩 Organized using Python functions.

## Requirements

- Python 3.x
